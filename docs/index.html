Auth Switcher

Hold several HTTP-auth logins for one site and switch between them without restarting Chrome.

Sites behind HTTP authentication — the credential box Chrome itself draws, not a login form on the page — are painful to test with more than one account. Chrome keeps those credentials in an in-memory auth cache that closing the tab does not clear, that “clear browsing data” does not clear, and that normally survives until you fully restart the browser.

What it does

  • Works with Basic, Digest, NTLM and Negotiate
  • Multiple sites, each with its own users and its own signed-in user — switching on UAT leaves DEV alone
  • Private windows run an independent session, so you can hold two users at once
  • Switching does not sign you out of your other sites
  • Encrypted export/import (AES-256-GCM) to move your users between machines
  • No server, no analytics, no telemetry, no remote code
QA accounts only. Credentials are stored unencrypted in Chrome's extension storage and are readable by anyone with access to your Chrome profile directory. Do not put credentials in it that would matter if they leaked.
